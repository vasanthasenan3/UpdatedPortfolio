Episode 01 · Web · 2026

Mentor Booking Platform

A web platform that connects mentees with mentors. Users build a profile and can switch mentoring on at any time. Mentors publish availability and mentees book a session directly.

ASP.NET Core MVCEF CoreAzure SQLOAuthSMTPBootstrap
  • Email/password, Google and Facebook login with ASP.NET Core Identity and OAuth.
  • Profile management with photo upload and a one-click mentee/mentor role switch.
  • Mentor availability with recurring time slots, plus search by name, skill or title.
  • Booking workflow with five states that blocks double-booking and self-booking.
  • SMTP emails to mentor and mentee whenever a booking is made or changes status.
  • SQL Server schema: Users, MentorProfiles, Skills, MentorAvailabilities, Appointments.

Episode 02 · Desktop · 2026

Supermarket Billing System

A WPF application that runs a supermarket's daily operations in one place: inventory, sales, customers, staff roles and reporting.

C#WPFADO.NETAzure SQL
  • Product management (add, edit, remove, categorise) with real-time inventory tracking.
  • Stock updates automatically on every sale, so no manual counting errors.
  • Billing module for sales, discounts and receipt printing, with each transaction stored in SQL Server.
  • Customer registration and profiles with full order history.
  • Custom sales and inventory reports that show what sells and what needs restocking.
